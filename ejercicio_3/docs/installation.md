# Installation


## Stable release

To install ejercicio_3, run this command in your terminal:

```batch

    $ pip install ejercicio_3
```

This is the preferred method to install ejercicio_3, as it will always
install the most recent stable release.

If you don't have [pip](https://pip.pypa.io) installed, this 
[Python installation guide](http://docs.python-guide.org/en/latest/starting/installation/) 
can guide you through the process.


## From sources

The sources for ejercicio_3 can be downloaded from the 
[Github repo](https://github.com/pabloaberbuj/ejercicio_3).

You can either clone the public repository:

```batch

    $ git clone git://github.com/pabloaberbuj/ejercicio_3
```

Or download the [tarball](https://github.com/pabloaberbuj/ejercicio_3/tarball/master):

```batch

    $ curl  -OL https://github.com/pabloaberbuj/ejercicio_3/tarball/master
```

Once you have a copy of the source, you can install it with:

```batch

    $ python setup.py install
```
